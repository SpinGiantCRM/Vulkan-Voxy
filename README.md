# Vulkan-Voxy

Vulkan-Voxy is a Vulkan/Beryl fork of Voxy for far-distance LoD rendering.

## Runtime requirements (Fabric)

Required mods:
- Fabric Loader
- Fabric API
- VulkanMod
- Beryl (if distributed separately in your modpack/runtime)

Not required:
- Sodium

Known incompatibility:
- Sodium is incompatible with VulkanMod 0.6.5, so Sodium should not be installed for Vulkan-Voxy Vulkan/Beryl testing.
